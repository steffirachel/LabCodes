# Supporting files included

Each assignment folder includes:
- `README.md`: question summary, program behavior, run commands, output meanings, observation guidance, inference and limitations.
- One `.cc` source file.
- `run_examples.sh`: sample command sequence to run from the NS-3 root folder.
- `observations_template.csv`: blank table for real measurements.

The package does not bundle the NS-3 framework itself. NS-3 is large and should be installed separately. The root README explains configuration, building, testing an example, copying the `.cc` files, and running them.
